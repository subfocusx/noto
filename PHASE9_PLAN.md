## Задача фазы

Фаза 9 отвечает на жалобу пользователя: «интерфейс непонятен, часть кнопок
дублируется, часть ничего не делает, теги нельзя добавить явно, плагины падают,
а сохранение ругается непонятной ошибкой».

Главный дефект, который нашлось при разборе: блоки `Query` / `Views` / `Tags`
**не фильтровали ничего** — результат запроса вычислялся (`ui.queryHits`), но
не рисовался нигде. Пользователь видел счётчик, но не видел отобранные
заметки, поэтому три блока и выглядели бессмысленными.

### Найденные при приёмке дефекты (исправлены)

| Дефект | Причина | Исправление |
|---|---|---|
| Тег добавлялся в текст **дважды** (`#idea #idea`), и крестик чипа вырезал только один | поле полосы отправлялось дважды: по Enter и по потере фокуса (фокус теряется при размонтировании поля) | `frontend/src/components/NoteTags.tsx`: флаг `submitted` переживает закрытие поля; `removeTag` в `App.tsx` вырезает **все** вхождения токена |
| Плагины `Graph`, `Tags`, `Activity`, `Link Cards` падали с «unknown permission: query.read» | право `query.read` использовалось плагинами, но отсутствовало в `PLUGIN_PERMISSIONS` | `frontend/src/plugins/manifest.ts` |
| Спека `plugins.spec.ts` ждала русские строки плагинов (`Слов: 2`, `Вставить шаблон`) | плагины переведены на английский вместе с оболочкой, спека осталась в старом виде | `e2e/specs/plugins.spec.ts` переведён на английские строки |
| Спека `shell.spec.ts` искала кнопку корзины в подвале сайдбара | корзина убрана из подвала (дубликат), в подвале только импорт/экспорт | `e2e/specs/shell.spec.ts` проверяет единственную кнопку подвала |
| Спека `editor.spec.ts` считала любой POST/PUT запросом записи | `POST /api/query` — это чтение, и его шлют плагины языка запросов | спека считает только пишущие эндпоинты (`/api/query` исключён) |
| Спека `shell-actions.spec.ts` падала на мобильном проекте | на узком экране сайдбар — выдвижная панель, кнопки дерева недоступны иначе | спека работает на desktop-проекте (мобильный вид закрыт спекой вьюпорта) |

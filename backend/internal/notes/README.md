# Пакет `notes`

## Назначение

Доменная логика Noto: дерево, создание и запись заметок, переименование,
перемещение, дублирование, корзина и восстановление, поиск, импорт и
экспорт, вложения, сверка файлов с базой (`reconcile`), атомарная запись на
диск, блокировки и точка расширения (хуки). Пакет **не знает про HTTP** и
работает с хранилищем только через `port.Store`.

## Публичные типы и функции

| Имя | Что это |
|---|---|
| `Service` | Сервис домена: дерево, CRUD, корзина, поиск, импорт/экспорт, вложения. |
| `NewService(cfg, store)` | Создаёт сервис поверх реализации `port.Store`. |
| `Error` / `NewError(code, message, cause)` | Типизированная ошибка с стабильным кодом. |
| `Code(err)` / `Message(err)` / `CurrentContent(err)` | Разбор ошибки (код, текст, текущая копия заметки при конфликте ревизии). |
| `WriteResult` | Результат записи: новая ревизия, признак конфликта. |
| `ReconcileReport` / `ReconcileOptions` | Отчёт сверки файлов с базой и параметры ( dry-run, `--apply`, `--drop-ghosts`). |
| `NoteOp` / `NoteEvent` / `Hook` / `NoteService` | Точка расширения: события изменений заметок для внешних потребителей. |
| `TrashPathPrefix` | Префикс пути корзины (`trash/`). |
| `BaseName(rel)` | Имя файла относительного пути. |
| `DiffLine` / `DiffOp` / `DiffLines(old, new)` | Построчный diff двух текстов (LCS): `equal`, `remove`, `add`. |
| `DerivedSummary` | JSON-блоб производных свойств заметки (заголовок, теги, флаги). |
| `ExtractAttachmentText(name, mime, content)` | Текст вложения для полнотекстового поиска (`text/plain`, `text/markdown`, `.md`, `.txt`). |

## История версий, кэш свойств, постраничное дерево

* **История версий.** Каждая запись содержимого заметки добавляет в историю
  неизменяемую версию (`port.Store`: `AppendVersion`, `ListVersions`,
  `GetVersion`). Сервис: `Versions`, `Version`, `RestoreVersion`,
  `DiffVersions`. Восстановление идёт через обычную запись, поэтому история
  остаётся «только на рост».
* **Кэш производных свойств.** Таблица `note_derived` (путь → JSON, время
  расчёта, флаг `stale`). Изменение заметки **помечает** кэш устаревшим, а не
  пересчитывает его; пересчёт — отдельный шаг (`RecomputeDerived`), который
  снимает флаг. Пересборка индекса (`Reindex`) кэш чинит.
* **Постраничное дерево.** `port.Store.ListChildrenPaged(parent, cursor,
  limit)` и `Service.Children` — постраничная выдача детей папки для
  ленивой загрузки дерева. Полный список (`Tree`) сохранён для совместимости.
* **Поиск по вложениям.** Текст вложения извлекается в домене
  (`ExtractAttachmentText`), индексируется в хранилище
  (`IndexAttachmentText`) и находится обычным поиском.
* **Имя.** Не длиннее 512 символов (`maxNameRunes`), управляющие символы
  запрещены (`invalid_name`), байт NUL вырезается из имени, а не отвергает
  его.

## Что нельзя импортировать отсюда

* `notes` не импортирует `internal/sqlitestore` — только `internal/port`
  (иначе движок хранилища перестаёт быть заменяемым);
* `notes` не импортирует `internal/api` — HTTP не протекает в домен;
* внутренние детали (`lockKeys`, `mergeStored`, `normalizeRel`,
  `writeFileAtomic`, `sniffAttachmentMIME`) не экспортируются наружу без
  причины: новые экспорты согласуются с владельцем пакета.

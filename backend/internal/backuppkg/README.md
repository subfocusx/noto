# Пакет `backuppkg`

## Назначение

Формат архива бэкапа: манифест (список файлов с суммами SHA-256), создание
архива из каталога данных, безопасное открытие и извлечение (защита от
zip-slip). Пакет ничего не знает про HTTP и про хранилище — только про файлы
и архив.

## Публичные типы и функции

| Имя | Что это |
|---|---|
| `Manifest` | Манифест архива: версия формата, время создания, список `FileEntry`. |
| `FileEntry` | Один файл манифеста: путь, размер, сумма SHA-256. |
| `NewManifest(createdAt)` | Пустой манифест с заданным временем. |
| `ParseManifest(data)` | Разбирает манифест из JSON (архивы v1 читаются). |
| `Archive` | Открытый архив. |
| `Open(path)` | Открывает архив и читает его манифест. |
| `Write(dir, out, manifest)` | Пишет архив (атомарно: temp + rename). |
| `Create(cfg, out)` | Создаёт бэкап каталога данных (путь возвращается). |
| `Snapshot(src, dst)` | Согласованный снимок каталога (в том числе базы через `VACUUM INTO`). |
| `IntegrityError` | Ошибка целостности архива. |
| `Mismatch` | Одно расхождение суммы или набора файлов. |

## Что нельзя импортировать отсюда

* `backuppkg` не импортируется из `internal/notes` и `internal/api` — только
  `cmd/backup` и `internal/restore`;
* логику восстановления нельзя дублировать здесь: она живёт в
  `internal/restore`;
* `Snapshot`, `copyTree`, `copyFile` — внутренние детали; наружу выставлены
  только `Create` и `Snapshot`.

## Проверка

`go test ./internal/backuppkg` · `scripts/restore-smoke.ps1` (бэкап →
восстановление → smoke во временном каталоге).

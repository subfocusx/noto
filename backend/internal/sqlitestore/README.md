# Пакет `sqlitestore`

## Назначение

Реализация `port.Store` поверх SQLite (`modernc.org/sqlite`, чистый Go, без
cgo): метаданные заметок, полнотекстовый индекс FTS5 с запасным вариантом
`LIKE`, вложения, корзина, схема и её миграции (`PRAGMA user_version`).

## Публичные типы и функции

| Имя | Что это |
|---|---|
| `Store` | Реализация `port.Store` поверх SQLite. |
| `Open(ctx, dbPath)` | Открывает (или создаёт) базу и применяет миграции. |
| `New(ctx, db)` | Создаёт хранилище поверх уже открытого `*sql.DB`. |

## Что нельзя импортировать отсюда

* `sqlitestore` не импортируется из `internal/notes` — домен знает только
  `port.Store`;
* `sqlitestore` не импортируется из `internal/api`;
* запросы собираются только с параметрами: склейка строк с пользовательскими
  данными запрещена (`internal/notes` и `internal/api` — тоже);
* `schemaVersion`, `schemaStatements`, `dataMigrations`, `fts5TableStatements` —
  внутренние детали схемы; их изменение требует правки `schema_compat_test.go`.

## Схема (версия 3)

| Таблица | Что хранит |
|---|---|
| `notes` | Метаданные заметок и папок, включая `created_at` (время создания никогда не меняется). |
| `notes_fts` / `notes_fts_v` | Полнотекстовый индекс заметок (обычная таблица и виртуальная FTS5). |
| `note_props` | Производные свойства заметки (заголовок, теги, флаги). |
| `note_versions` | История версий заметки: путь, ревизия, заголовок, текст, время. Неизменяемая. |
| `note_derived` | Кэш производных свойств: путь → JSON, время расчёта, флаг `stale`. |
| `attachment_text` | Текст, извлечённый из вложения, чтобы он был находим поиском. |
| `attachment_fts_v` | FTS5-индекс текста вложений. |
| `attachments`, `trash` | Вложения и корзина. |

Миграции идемпотентны и выполняются при каждом открытии: `dataMigrations`
заполняют `created_at` у старых строк (только там, где он ещё нулевой) и не
трогают уже заполненные значения.

FTS5 определяется **один раз, при открытии** (`detectFTS5`). Запасной путь
`LIKE` используется только когда FTS5 действительно недоступен; он просматривает
весь индекс, поэтому находит те же заметки. Общий набор поисковых случаев для
обеих ветвей — `search_corpus_test.go`.

## Проверка

`go test ./internal/sqlitestore` (включая `schema_compat_test.go`) ·
`go run ./cmd/smoke`.

# Пакет `config`

## Назначение

Превращает переменные окружения в `config.Config`: адрес, каталог данных,
каталоги заметок, вложений и корзины, путь к базе, разрешённые источники,
режим обслуживания. Это **замороженный контракт**: его читают все, но не
меняют без синхронного изменения документации.

## Публичные типы и функции

| Имя | Что это |
|---|---|
| `Config` | Полная конфигурация приложения (структура с полями окружения). |
| `Load()` | Читает окружение и возвращает `Config` (с значениями по умолчанию). |

## Что нельзя импортировать отсюда

* `config` не импортируется из `internal/port`, `internal/model`,
  `internal/sqlitestore` — эти пакеты не знают об окружении;
* в `config` не добавляются новые зависимости: пакет — лист графа;
* значения по умолчанию не меняются молча: любое изменение требует записи
  в `docs/CONTRACT.md` и `.env.example`.

## Проверка

`go test ./internal/config` · полный список переменных — `.env.example` и
`docs/CONTRACT.md`.

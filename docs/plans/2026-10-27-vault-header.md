# План: шапка хранилища (левая колонка)

Дата: 2026-10-27. Владелец: скриншот шапки с жалобой «выглядит стремно» и просьбой
посмотреть, как это делают другие проекты.

## Goal

Шапка левой колонки (хранилище заметок) выглядит как шапка сильного приложения:
одна строка, тихая иконка, имя хранилища, действия справа. Абсолютный путь не
занимает вторую строку в шапке.

Критерии приёмки:

- шапка — одна строка `--header-height` (40 px);
- иконка хранилища — 16 px, приглушённый цвет, без цветной плитки;
- имя хранилища — кнопка-переключатель хранилища (как в Obsidian), с шевроном,
  который появляется при наведении;
- полный путь виден в подсказке, в меню хранилища и в меню действий колонки;
- действия шапки (новая заметка, замок, меню) остаются на месте и работают;
- тесты, типы, сборка, границы и e2e — зелёные; скриншот приложен к отчёту.

## Context

Текущее состояние (`frontend/src/components/sections/ExplorerSection.tsx:596-670`,
`frontend/src/styles/components.css:275-380`):

- `.vault-header` — flex-колонка, две строки внутри 40 px;
- первая строка: `.vault-header-icon` (плитка 22×22 с `--accent-subtle`) + имя +
  три кнопки действий;
- вторая строка: `.vault-header-path` — моноширинный 10 px, `direction: rtl`,
  из-за чего путь читается как «заголовок», а не как деталь; выравнивание
  визуально центрирует его.

Как это сделано в сильных приложениях (наблюдения, без доступа к сети):

| Приложение | Шапка хранилища | Путь |
|---|---|---|
| Obsidian | иконка 16 px приглушённая + имя 13 px + шеврон на наведении, клик — меню хранилища | только в меню |
| VS Code (Explorer) | метка раздела 11 px капителью, действия справа; папка — отдельная строка-раздел | в breadcrumb, не в шапке |
| Notion | имя рабочего пространства 14 px + шеврон | нет |
| Finder | имя папки в заголовке окна, путь — отдельной полосой-hлебными крошками | не в заголовке |
| Zed | имя проекта 12 px приглушённо внизу сайдбара | в статусной строке |

Вывод: постоянный абсолютный путь в шапке — шум; он живёт в подсказке и в меню.
`VaultSwitchMenu` уже показывает текущий путь (`.vault-menu-current-path`), то есть
информация не теряется.

## Approach

Одна строка вместо двух:

```
[папка 16px muted] [имя 13px semibold ⌄] ......... [+][замок][⋯]
```

- `.vault-header` — строка (`display: flex`), `gap: var(--space-1)`;
- `.vault-header-icon` — 16 px, `--fg-muted`, без плитки;
- `.vault-header-name` — кнопка, если хранилище можно сменить (`onChooseVault`),
  иначе текст; `aria-label` = «{имя} — сменить хранилище заметок» (правило WCAG
  2.5.3 «label in name»: видимое имя входит в доступное имя); шеврон
  `chevron-down` появляется при наведении/фокусе (`opacity`), место под него
  зарезервировано — вёрстка не прыгает;
- путь уходит из шапки: он в `title` кнопки, в меню хранилища и в меню
  действий колонки;
- при `vaultFixed` кнопка остаётся, но с `aria-disabled` и подсказкой
  «хранилище задано окружением» — как сейчас.

## Tasks

1. `frontend/src/components/sections/ExplorerSection.tsx` — новая разметка шапки:
   одна строка, имя-кнопка как триггер меню хранилища (`ref` триггера
   переносится на кнопку), вторая строка пути удаляется.
2. `frontend/src/styles/components.css` — правила шапки: `.vault-header`
   (строка), `.vault-header-icon` (16 px, muted), `.vault-header-name`

   (появляется при наведении); правила `.vault-header-main`, `.vault-header-sub`,
   `.vault-header-triggers`, `.vault-header-path` удаляются.
3. `frontend/src/i18n/catalog/{en,ru}/sections.ts` — ключ
   `explorer.changeStorageNamed` («{name} — сменить хранилище заметок»).
4. Тесты: `frontend/src/__tests__/vault-switch.test.tsx` (триггер меняет имя),
   новый `frontend/src/__tests__/vault-header.test.tsx` (одна строка, нет пути,

   (роль кнопки по регулярному выражению).
5. Документация: `docs/DESIGN_SYSTEM.md` (§3.1 — «шапка хранилища (имя + …)»,
   новый раздел о шапке), `IMPLEMENTATION_STATUS.md` (фаза 21).
6. Проверка: `npm run typecheck`, `npx vitest run`, `npm run check:boundaries`,
   `npm run build`, `npx playwright test` (полный), скриншот.

## Verification

- unit: новая спека шапки + правка трёх тестов меню хранилища;
- e2e: `storage-menu.spec.ts` (переключение хранилища через имя), полный прогон;
- визуально: скриншот 1440×900 — шапка в одну строку, без плитки и пути.

## Decisions / Risks

- Путь больше не виден постоянно. Он остаётся в подсказке, в меню хранилища и
  в меню действий; правило DESIGN_SYSTEM §3.1 обновляется в этом же изменении.
- Имя шапки — кнопка: доступное имя содержит видимое имя (WCAG 2.5.3), e2e
  ищет кнопку регулярным выражением.
- Шестрон появляется при наведении: место зарезервировано, вёрстка не прыгает.
- Меню действий колонки не меняется.

# Пакет `model`

## Назначение

Общие типы предметной области, которые одновременно являются JSON-контрактом
API: узел дерева, содержимое заметки, результат поиска, вложение, результат
импорта, конверт ошибки. Это **замороженный контракт**: изменение поля
здесь меняет ответы API.

## Публичные типы и функции

| Имя | Что это |
|---|---|
| `NodeType` | Тип узла дерева (`folder` / `file`). |
| `Node` | Узел дерева: путь, имя, тип, родитель, ревизия, счётчики. |
| `NoteContent` | Содержимое заметки: путь, текст, ревизия. |
| `SearchHit` | Один результат поиска: путь, имя, вид совпадения, фрагмент. |
| `Attachment` | Вложение: идентификатор, имя, MIME-тип. |
| `ImportResult` | Итог импорта: сколько принято, переименовано, пропущено. |
| `APIError` | Тело ошибки: стабильный `code` и `message`. |
| `ErrorBody` | Конверт ответа с ошибкой: `{"error": {...}}`. |

## Что нельзя импортировать отсюда

* `model` — лист графа: он не импортирует ничего из `backend/internal`;
* `model` не импортируется в `internal/port` и `internal/sqlitestore`
  только как «структуру ради структуры»: типы здесь — это контракт;
* логика (вычисление полей, проверки) в `model` не помещается — она в
  `internal/notes`.

# Пакет `sealed`

## Назначение

Слепое хранилище объектов запечатанного режима: сервер хранит байты под
идентификатором и **никогда не видит ключа**. Здесь же — заглушка хранилища
для открытых эндпоинтов в запечатанном режиме: она отвечает ошибкой
`vault_sealed`.

## Публичные типы и функции

| Имя | Что это |
|---|---|
| `Store` | Хранилище объектов: чтение, запись, удаление по идентификатору. |
| `New(root)` | Открывает хранилище в каталоге `root`. |
| `NewBlockedStore()` | Заглушка `port.Store`, отвечающая `vault_sealed`. |
| `ErrVaultSealed` | Ошибка `vault_sealed`. |

## Что нельзя импортировать отсюда

* `sealed` не импортируется из `internal/notes` и `internal/sqlitestore` —
  это отдельный режим, а не часть дерева заметок;
* `sealed` не знает и не может знать ключевой материал: шифрование делает
  браузер (`frontend/src/core/crypto`, `frontend/src/core/vault`);
* `sealed` не импортируется в `internal/api` напрямую, кроме регистрации
  маршрутов запечатанного режима.

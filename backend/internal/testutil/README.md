# Пакет `testutil`

## Назначение

Вспомогательный код тестов: хранилище в памяти (`MemStore`) — вторая
реализация `port.Store` для конформанс-тестов, упрощённый поиск с
подсветкой и снимками, фабрики тестовой конфигурации и тестового сервиса.

## Публичные типы и функции

| Имя | Что это |
|---|---|
| `MemStore` | Хранилище в памяти, реализующее `port.Store`. |
| `NewMemStore()` | Создаёт `MemStore`. |
| `TrashRow` | Запись корзины в памяти. |
| `NewTestConfig(t)` | Тестовая `config.Config` во временном каталоге. |
| `NewTestService(t)` | Тестовый `*notes.Service` поверх `MemStore`. |

## Что нельзя импортировать отсюда

* `testutil` **никогда** не импортируется в рабочий код: только из
  `_test.go` и из `internal/port/porttest`;
* поведение `MemStore` обязано совпадать с `sqlitestore` — расхождения
  фиксируются в `porttest` и должны быть нулевыми;
* тестовые упрощения (например, поиск без FTS5) не должны имитировать
  оптимизацию: тест проверяет контракт, а не скорость.

## Проверка

`go test ./internal/testutil` · `go test ./internal/port` (конформанс-набор).
